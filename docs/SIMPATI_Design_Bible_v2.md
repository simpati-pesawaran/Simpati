# SIMPATI Design Bible v2

## Visi
SIMPATI adalah aplikasi PWA pemerintahan dengan tampilan modern, premium, ringan, mobile-first.

## Prinsip
- Dokumen ini adalah acuan utama.
- UI tidak boleh diubah tanpa persetujuan.
- Fokus performa dan konsistensi.

## Dashboard
- Layout khusus.
- Hero gradient merah→oranye.
- Status bar menyatu.
- Logo 3D.
- Lonceng log aktivitas.
- Sapaan admin.
- Tanggal.
- Kartu Total Kegiatan & Audiensi.
- Kontainer putih radius besar.
- Menu: Agenda, Calendar, Galeri, Usulan Kegiatan, Log Aktivitas.
- Ringkasan agenda hari ini (yang belum lewat).

## Bottom Navigation
- Beranda
- FAB Agenda
- Akun
Tetap ukuran mobile di desktop.

## Modul
Agenda, Calendar (Google Calendar), Galeri (foto→WebP, PDF preview WebP), Usulan Kegiatan, Log Aktivitas.

## Fitur Global
- Global Search
- Filter Tanggal
- Offline Cache PWA

## Tidak Masuk v2
- Dark Mode

## Standar UI/UX
Target kualitas aplikasi terbaik 2026: modern, premium, mobile-first, animasi halus, komponen konsisten, performa tinggi.
