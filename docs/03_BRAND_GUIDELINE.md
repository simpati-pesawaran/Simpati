## Logo System

### Primary Logo

The SIMPATI logo is a **geometric shield with calendar symbol** representing protection and organization. It conveys:

- **Shield shape**: Security, protection, government authority
- **Calendar symbol**: Organization, scheduling, agenda management
- **Gradient**: Innovation, modern technology
- **Gold accents**: Excellence, prestige

### Logo Variations

#### 1. Full Logo (Horizontal)

`
┌────────────────────────────────────────────────────────────┐
│                                                            │
│    ┌──────┐                                               │
│    │ LOGO │    SIMPATI                                   │
│    └──────┘    Sistem Informasi Manajemen Protokol...     │
│                                                            │
└────────────────────────────────────────────────────────────┘
`

**Use for:**
- Website headers
- App splash screen
- Presentation materials

#### 2. Icon Only

`
┌──────────────┐
│              │
│    [LOGO]    │
│              │
└──────────────┘
`

**Use for:**
- App icon
- Favicon
- Favicon
- Social media profile
- Small contexts where full name is unnecessary

#### 3. Stacked Logo

`
┌────────────────┐
│                │
│    [LOGO]      │
│                │
│    SIMPATI     │
│                │
└────────────────┘
`

**Use for:**
- App store listing
- Social media cover
- Merchandise

### Logo Clear Space

Always maintain minimum clear space around the logo.

`
┌─────────────────────────────────┐
│                                 │
│    ┌───┐                        │
│    │   │  ← Minimum: 1x logo   │
│    └───┘    height/width       │
│                                 │
└─────────────────────────────────┘
`

### Minimum Sizes

| Context | Minimum Width |
|---------|---------------|
| Digital (screen) | 32px |
| Print | 24mm |
| Favicon | 16px |

`

│                                                 │
│   PRIMARY GRADIENT                              │
│   #9333ea → #3b82f6                            │

- Primary buttons
- Active states

## Typography

### Primary Font: Inter

**Inter** is our primary typeface for its excellent readability and modern appearance.

### Font Weights

| Weight | Value | Usage |
|--------|-------|-------|
| Regular | 400 | Body text |
| Medium | 500 | Labels, emphasis |

## Brand Voice

### Voice Attributes

#### Professional
- Clear, direct language
- Formal enough for government context
- Avoid slang and casual expressions

#### Approachable
- Warm and friendly tone
- Use "kami" not impersonal language
- Explain technical terms

#### Modern
- Fresh, contemporary language
- Avoid bureaucratic jargon
- Use active voice

### Do's and Don'ts

| Do | Don't |
|----|-------|
| "Agenda berhasil dibuat" | "Operasi CREATE berhasil" |
| "Mohon tunggu sebentar" | "Please wait" |
| "Terjadi kesalahan" | "Error 500: Internal Server Error" |
| "Tidak dapat menyimpan" | "Failed to persist data" |

### Example Copy

#### Success Message
`
✅ Agenda berhasil dibuat!

Agenda "Rapat Koordinasi" telah dijadwalkan 
untuk besok pukul 09:00.
`

#### Error Message
`
⚠️ Terjadi kesalahan

Tidak dapat menyimpan agenda. 
Pastikan koneksi internet stabil dan coba lagi.
`

#### Empty State
`
📅 Belum Ada Agenda

Mulai dengan membuat agenda pertama 
untuk hari ini.
`

## Usage Rules

### Logo Don'ts

- ❌ Don't stretch or distort the logo
- ❌ Don't change the logo colors
- ❌ Don't add effects to the logo
- ❌ Don't place on busy backgrounds
- ❌ Don't rotate the logo
- ❌ Don't use outdated versions

### Color Don'ts

- ❌ Don't use unauthorized colors
- ❌ Don't create new gradients
- ❌ Don't use gradients on text
- ❌ Don't use color as the only indicator

### Typography Don'ts

- ❌ Don't use non-approved fonts
- ❌ Don't mix font weights incorrectly
- ❌ Don't use font sizes below minimum

## Assets

### Logo Files

All logo assets are located in: docs/assets/logo/

| File | Description | Format |
|------|-------------|--------|
| simpati-icon.svg | Main logo | SVG |
| simpati-favicon.svg | Favicon | SVG |
| simpati-icon.png | Main logo | PNG (for fallback) |
| simpati-favicon.ico | Favicon | ICO |

### Usage

**Web:**
`html
<!-- SVG (preferred) -->
<img src="/logo/simpati-icon.svg" alt="SIMPATI Logo" />

<!-- PNG fallback -->
<img src="/logo/simpati-icon.png" alt="SIMPATI Logo" />
`

**React:**
`	sx
import Logo from '@/assets/logo/simpati-icon.svg';

<Logo className="h-8 w-auto" />
`

### App Icons

The icon should be used for:
- PWA manifest
- iOS home screen
- Android home screen
- App store listing

**Required sizes:**
- 16x16 (favicon)
- 32x32 (favicon @2x)
- 192x192 (PWA)
- 512x512 (PWA @2x)
- 1024x1024 (App store)
